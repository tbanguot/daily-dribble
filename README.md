 # Daily Dribbble

 A frontend recreation of a Dribbble-inspired daily design challenge, built as part of the Scrimba Frontend Developer path.

 ## Overview

 This project focuses on translating a visual design into a responsive, polished web interface using modern frontend fundamentals.

 ## Features

 - Responsive layout for desktop and mobile screens
 - Dribbble-inspired visual design
 - Reusable UI structure and styling
 - Clean, accessible markup

 ## Getting started

 Clone the repository and open the project directory:

 ```bash
 git clone <repository-url>
 cd daily-dribble
 ```

 Install dependencies if the project uses them, then start the development server:

 ```bash
 npm install
 npm run dev
 ```

 Open the local URL shown in the terminal to view the project.

 ## Built with

 - HTML
 - CSS
 - JavaScript

 ## Project goal

 The goal of this challenge is to practise converting a design concept into a functional, responsive frontend while improving layout, styling, and attention to detail.
